# Sprint Plans — 3 Two-Week Sprints

## Sprint 1 — Discovery and setup

**Goal created:** Define the problem, stakeholders, and a usable backlog, and set up tracking before building.

**Work I created and analysed:**
- Stakeholder map and communication cadence
- Current-state analysis of the 21-day manual process
- Charter, scope in/out, and success criteria
- Backlog refinement for Epics 1 and 2
- Jira-style board structure: To Do / In Progress / In Review / Done
- Definition of Done for stories and for the pilot

**Sprint review point:** Charter and backlog reviewed; pilot partner profiles selected for simulation.

## Sprint 2 — Core build

**Goal created:** Build the guided checklist, account setup view, and basic data import.

**Work I created:**
- Guided checklist flow with stage owners and progress tracking
- Account setup view (demo in `demo/index.html`)
- Basic data import flow with success/error summary
- Training notes linked to major stages

**Sprint review point:** Core flow walkthrough with simulated Customer Success feedback; two usability issues logged for Sprint 3.

## Sprint 3 — Pilot, training, and go-live

**Goal created:** Test the flow with a simulated pilot, fix the highest-impact issues, and prepare a go-live playbook.

**Work I created and analysed:**
- Pilot run with 2–3 simulated partner/customer profiles
- Pilot feedback analysis: clarity, blockers, and time in stage
- Two flow redesigns based on pilot feedback: earlier security check, and clearer customer vs. internal actions
- Training handoff checklist and go-live checklist
- Retrospective (see `docs/retrospective.md`)

**Sprint review point:** Go-live readiness review against the charter success criteria, with open items listed for a future iteration.
